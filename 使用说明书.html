日程管理 — 使用说明书 & 更新日志

v1.0 · 2026-08-07

一、快速开始

启动方式

方式说明
双击 日程管理.exe打包后直接运行
启动日程管理.bat开发模式启动
静默启动.bat无窗口启动（适合开机自启）

最小化策略

关闭主窗口 不会退出程序。程序会在系统托盘运行，弹窗定时器持续生效。

  • 双击托盘图标 → 恢复主窗口
  • 右键托盘 → 立即记录 / 退出

开机自启

打开主窗口 → 设置（⚙）→ 系统集成 → 开启「开机自动启动」。

数据位置

所有日程、心情、备注保存在 OneDrive/schedule-data/，自动跨设备同步。

二、主功能说明

2.1 周视图（日程总览）

  • 时间轴：从 6:00 开始，符合自然作息。滚轮可缩放（67%〜167%）
  • 午夜分隔线：23:00→00:00 处有加深线
  • 心情组件：每天下方有彩色圆点，点击弹出绿→红五色菜单
  • 备注：点击「备注」可为整周写备注
  • 视图切换：头栏「周 | 月」切换

添加日程：

  • 点击空白格 → 弹出编辑
  • 右下角「+」浮动按钮 → 手动添加（自动推算当天最后一段结束时间）
  • 点击已有日程块 → 编辑
  • TimeBar 拖动条编辑时间：
    • 拖动圆点把手调整开始/结束
    • 按住 Shift + 滚轮：平移视窗（视野左右移动，不改变选择）
    • 滚轮：缩放可见范围
    • 「吸附」开关：开=松手对齐 30 分钟，关=保留任意分钟
    • 「到现在」按钮：快速设置结束时间为当前时刻

2.2 月视图

  • 头栏点击「月」进入
  • 三个月份连续纵列：中心月高亮，上/下月 45% 淡入
  • 每周一行：显示 7 天日期 + 心情点
  • 本周标识：左侧 4px 竖线
  • 心情平均色：整周底色由该周心情颜色 RGB 平均得出
  • 跨月周：在相邻两月都显示，中心月天数始终高亮
  • 翻月：滚到底/顶自动切月，新月份平滑居中
  • 跳转周视图：点击任意周条 → 跳转到该周

2.3 快捷弹窗（每 2 小时）

  • 8:00〜20:00，逢偶数整点自动弹出
  • 累积时段：弹窗未处理时，下次触发自动扩大会话范围
  • 常用项：预设分类+内容，一键填入
  • 多选分类：点击「+分类」追加标签，首个为主色
  • 添加 / 进行中：添加完成段或标记为进行中
  • 完成 / 等会儿记录：都关闭弹窗

三、导入导出（数据迁移）

  • 设置面板 → 数据管理
  • 导出备份：下载完整 JSON（日程 + 备注 + 心情 + 设置 + 频率统计）
  • 导入备份：
    • 预览阶段：显示新旧记录数、冲突数
    • 冲突警告
    • 合并策略：智能合并（冲突取较新版本 / 完全替换）

四、分类与颜色

  • 11 个内置分类：工作 / 学习 / 实验 / 写作 / 会议 / 阅读 / 运动 / 休息 / 社交 / 吃饭 / 赶路
  • 莫兰迪色盘，每个分类有唯一色值
  • 自定义分类自动分配新颜色
  • 日程块在周视图以分类色显示

五、心情记录

  • 绿→红五色渐变：很好 / 不错 / 一般 / 不太好 / 糟糕
  • 周视图：每天下方的圆点 + 弹出菜单
  • 月视图：每天心情点 + 周底色平均
